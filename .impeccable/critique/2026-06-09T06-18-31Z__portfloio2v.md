## Priority Issues (Post-Fix)

### No P0 or P1 issues remain.

### [P2] Archive section "code ↗" and "demo →" are not real links

**What:** The "Other / Archive" section on the projects page uses `span` elements with `cursor-pointer` instead of `Link` components.

**Why it matters:** Users will click these and nothing will happen. This is a dead link, just styled differently.

**Fix:** Either make them real links or remove the `cursor-pointer` and `hover` styles to make them static text.

**Suggested command:** `impeccable fix projects` (archive section)

### [P2] The "based" row could be more useful

**What:** The "based" row is now static text. It doesn't do anything.

**Why it matters:** It takes up space in the channels grid without providing value. Either remove it or make it useful (e.g., link to a map, or show timezone conversion).

**Fix:** Remove the "based" row entirely, or replace it with a more useful channel (e.g., "cal.com" link if you have one).

**Suggested command:** `impeccable clarify footer`

### [P2] Terminal typing animation could be faster

**What:** The terminal types ~33 lines at 70ms per line. This takes ~2.3 seconds.

**Why it matters:** A recruiter scanning quickly might scroll past before the typing finishes. The interactive input only appears after typing is complete.

**Fix:** Reduce the delay to 40ms per line, or show the input prompt immediately while typing continues.

**Suggested command:** `impeccable optimize terminal`

### [P3] The "show 4 more entries" button text could be more contextual

**What:** The button says "show 4 more entries →".

**Why it matters:** The number is accurate but dry. Could be more engaging.

**Fix:** Consider "show older entries →" or "show full history →" to give context about what the 4 entries are.

**Suggested command:** `impeccable clarify timeline`
