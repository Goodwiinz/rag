Capabilities
Intelligence, not just retrieval

NOUS combines semantic search, knowledge graphs, and generative AI into a unified research workflow.

Semantic Search

Vector-powered retrieval across documents, PDFs, and research papers with contextual re-ranking.

Knowledge Graphs

Entity extraction and graph-based reasoning powered by Neo4j for deep relational understanding.

Document Intelligence

Ingest and analyze PDFs, papers, and multimodal content with automatic metadata extraction.

AI Writing Assistant

Generate drafts, summaries, bibliographies, and research notes with context from your corpus.

Agent Workflows

LangGraph-powered research agents with intent routing, tool use, and human-in-the-loop control.

Secure by Design

Row-level security, validated enums, explicit CORS allowlists, and WebSocket auth via protocol headers.

Architecture
Built on a modern stack

A composable architecture designed for scale, observability, and developer experience.

Frontend

Next.js 15 with TypeScript strict mode, shadcn/ui components, and real-time SSE streaming.

Backend

FastAPI with async endpoints, structured logging via structlog, and Prometheus metrics.

Vector Store

Qdrant for high-performance semantic search with contextual re-ranking.

Graph Database

Neo4j for entity relationships, knowledge graph queries, and relational reasoning.

Relational DB

PostgreSQL with row-level security, validated enums, and async session management.

Agent Engine

LangGraph StateGraph with intent classification, checkpointing, and human-in-the-loop.
