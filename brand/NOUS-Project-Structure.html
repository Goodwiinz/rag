High-Level Architecture

Frontend

Next.js 15 · TypeScript · App Router
30+ component domains, shadcn/ui design system, Zustand stores, SSE streaming for agent chat, WebSocket for realtime updates. NOUS brand with Sol gold accent.

Backend

FastAPI · Python · Async
13 API route groups, LangGraph agent system with 4 subgraphs, Celery task queue, Alembic migrations, structlog observability, circuit breaker resilience.

Data Layer

PostgreSQL · Qdrant · Neo4j · Redis
Hybrid storage: relational data in Postgres, vector embeddings in Qdrant, knowledge graph in Neo4j, caching and sessions in Redis. 20+ SQL migrations.

Infrastructure

Docker · K8s · Terraform · Nginx
14 Docker Compose configurations, Kubernetes manifests, Terraform IaC, Prometheus/Grafana monitoring, CI/CD via GitHub Actions, 80+ utility scripts.
