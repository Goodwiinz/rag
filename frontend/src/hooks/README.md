# hooks

Custom React hooks for the NOUS platform. All hooks follow the `useX` naming convention and live at this level or in a named subdirectory (`chat/`, `analytics/`, `upload/`). Each hook encapsulates one domain of state or side-effect and composes Zustand stores, TanStack Query, or raw browser APIs as appropriate for that domain.

## shared patterns

**TanStack Query** (`@tanstack/react-query`) is used for all read-heavy server state: analytics, evaluations, evidence, dashboards, reports, and optimistic uploads. Mutations call `queryClient.invalidateQueries` or patch the cache directly.

**Custom fetch** (raw `api-client`) is used for stateful document operations (`useDocuments`) and auth flows where TanStack Query's caching semantics would complicate error handling (401 triggers immediate `handleAuthError` + store clear).

**Zustand stores** are the source of truth for chat state, auth state, and sidebar state. Hooks are thin selectors + action binders over those stores, not independent state owners.

**SSE streaming** (`EventSource`-style via `agentChatService`) is managed in `chat/useChatStreaming`; the agent endpoint is `/api/v1/agent/stream`.

## gotchas

- Document/upload processing status is polled, not pushed over WebSocket — the old FE WebSocket realtime stack (`useWebSocket`, `useWebSocketConnection`, `useRealtimeProcessing`, `useDocumentProcessingStatus`) never worked end-to-end (handshake/payload-shape mismatch, server emitted no events) and was removed. `uploadService.ts` and `useDocuments.ts` poll `GET /processing/documents/{id}/status` / the documents list instead.
- `useDocuments` normalises backend field aliases (`uploaded_by_user_id` / `user_id`, `document_type` / `file_type`, etc.) because the API shape has evolved. The status mapping is lowercase: `'pending'` → `'queued'`, `'completed'` → `'indexed'`.
- `useAuth` throws if called outside `AuthProvider`. Mount `AuthProvider` once at the application root.
- `useNotificationBridge` has no return value; it only produces side effects. Mount it once near the root alongside `AuthProvider`.
